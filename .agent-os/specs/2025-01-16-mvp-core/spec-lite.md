# Mobile Report App MVP - Lite Summary

A Progressive Web App (PWA) for handwerk businesses that digitizes field operations, enabling workers to track time, view orders, and create digital reports with photos and signatures - all while working offline.

## Key Points
- **Offline-First PWA**: Works without internet, syncs when connected, optimized for Android tablets
- **Core Field Operations**: Order viewing, time tracking, digital report creation with photos and customer signatures
- **Mock Data MVP**: Standalone application using test data to validate workflows before MSSQL integration in Phase 2
- **Admin-Managed Users**: Simple user management with role-based access (worker, manager, admin)
- **8-10 Week Timeline**: Focused MVP to validate core use cases with handwerk field workers
- **Vue.js + IndexedDB**: Modern web stack with local storage for offline capability and responsive design
